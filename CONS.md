# CONS.md

> Consequences. The real reason this account is being abandoned.

## The short version

I made a **14-day commit streak**. Then I missed one day. Then I started again the same day. The graph didn't register the restart. It kept showing the old streak, then suddenly corrected to a **5-day streak** starting from the wrong date. Meanwhile, commits I was pushing were being counted on the repository pages but not on the contribution graph.

I spent days trying to figure out why. Emails verified. Default branch confirmed. Private contributions enabled. New files, edited files, direct commits, PR merges — I tried everything.

The answer is the same one GitHub quietly admits if you dig far enough: **the contribution graph only counts commits that pass a specific filter** — default branch only, verified email only, non-fork only, private-only-if-enabled. Everything else is invisible, no matter how much work you put in.

## What this cost me

- **My streak.** Gone.
- **My time.** Hours I'll never get back, spent debugging a graph instead of building things.
- **My trust.** I made this profile professional *for* GitHub. GitHub answered by counting a fraction of my work.
- **My focus.** I started building repos as streak-fodder instead of as things I actually cared about. That's the worst part.

## What I'm doing about it

I'm not deleting this account. I'm not rage-quitting. I'm **changing strategy**.

1. **`realximanta` becomes a backup account.** I'll still fork things, still merge things, still keep the repos alive. But I won't perform for the graph anymore.
2. **A new persona is coming.** Different account, different focus, different rules for myself. The work continues — just not under this name.
3. **The contribution graph can keep its filters.** I'll count my own progress from now on.

## What I'm not doing

- I'm not blaming other developers. This isn't a war on open source.
- I'm not abandoning the code. The repos stay. The MIT licenses stay.
- I'm not pretending the graph doesn't matter. It does matter — that's exactly why it hurts.

## To GitHub

You have a good platform. You also have a contribution system that rewards appearance over output, and hides work from the people who did it. I hope that changes. I won't be here to see it if it does.

## To whoever reads this

If you're chasing a streak and it's eating your week — stop. The graph is not your worth. The code is.

— **Himanta Bhuyan**, signing off on 01-01-2027.
